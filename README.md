# بوصلة الذكاء الاصطناعي · Bawsala AI

تطبيق أندرويد عربي: محادثة بالذكاء الاصطناعي، إنشاء صور، بناء تطبيقات ومواقع، وكيل مهام، وأصوات عصبية تعمل بلا إنترنت. بياناتك تبقى على جهازك.

**الموقع الرسمي:** http://bawsala.unaux.com/

- `app/` كود التطبيق (WebView + Java، بدون Android SDK)
- `website/` ملفات الموقع الرسمي
- `model/` أدوات تدريب نموذج لغوي خاص
