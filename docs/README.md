# موقع بوصلة (Bawsala) — ملفات الموقع

موقع ثابت (Static) متعدد الصفحات بدون أي مكتبات خارجية: HTML + CSS + JavaScript فقط. الخط: خط النظام العربي (لا خطوط خارجية).

## الصفحات
| الملف | المحتوى |
|---|---|
| `index.html` | الرئيسية: تعريف، أرقام، مزايا، لقطات، خطوات، مزوّدون، أسئلة شائعة |
| `features.html` | المزايا بالتفصيل |
| `guide.html` | الشروحات الكاملة (التثبيت، المفتاح، المحادثة، الصور، البناء، الوكيل، الأصوات، الأمان، حل المشكلات) |
| `download.html` | تحميل الـAPK + بصمة SHA-256 |
| `about.html` | المطوّر والشركة والخدمات والتواصل والإسناد |
| `privacy.html` / `terms.html` | سياسة الخصوصية وشروط الخدمة |

## البنية
```
css/base.css        المتغيرات والنظام الخطي والألوان (داكن/فاتح)
css/layout.css      الشبكة والهيدر والفوتر
css/components.css  الأزرار والبطاقات والتبويبات والأسئلة...
css/motion.css      الحركات (3 أنظمة) وقسم البطل
js/config.js        ← عدّل هنا: الأسماء، الروابط، البريد، رابط التحميل
js/main.js          السلوك: ظهور عند التمرير، باراللاكس، ميل ثلاثي الأبعاد، عدّادات، تبويبات...
img/                الشعار ولقطات الشاشة (webp)
```

## أنظمة الحركة الثلاثة
1. **الظهور عند التمرير** (Scroll reveal) بتتابع متدرّج.
2. **الحركة المحيطة**: خلفية Aurora تتبع المؤشر، وهواتف عائمة بباراللاكس.
3. **التفاعلية**: ميل ثلاثي الأبعاد للبطاقات، أزرار مغناطيسية، عدّادات، كتابة متحرّكة للكلمة الرئيسية، وتبويبات.

كلها تُعطَّل تلقائياً لمن فعّل «تقليل الحركة» في جهازه (`prefers-reduced-motion`).

## التخصيص
* غيّر الاسم/الشركة/البريد/الروابط من `js/config.js` فقط.
* اسم الشركة الحالي «وكالة كروري للتطوير» اسم مؤقت اقترحناه، **غيّره لاسم شركتك الفعلي**.
* **المظهر داكن فقط. بوابة التحميل:** كل زر «حمّل التطبيق» يفتح نافذة كلمة السر.  رابط الـAPK مخزَّن **مشفّراً** (AES-GCM بمفتاح مشتق من رمز المطوّر عبر PBKDF2) داخل `js/config.js` ولا يظهر إلا بعد إدخال الرمز الصحيح في `download.html`. الرمز نفسه غير موجود في أي ملف.
  لتغيير الرمز أو الرابط أعد توليد الكتلة `apkLocked`. تنبيه صريح: هذه حماية من جهة المتصفح فقط؛ رمز من 6 أرقام يمكن تخمينه بهجوم مباشر على الملف (مكلف لكنه ممكن)، ومن يعرف رابط GitHub نفسه يستطيع فتحه. للحماية الحقيقية استخدم حماية الاستضافة (Cloudflare Access أو Netlify Password) أو مستودعاً خاصاً.
* بصمة SHA-256 في `download.html` تخص ملف الـAPK وقت إعداد الموقع؛ حدّثها عند كل إصدار جديد.

## النشر
ارفع المجلد كما هو إلى أي استضافة ثابتة (GitHub Pages، Netlify، Cloudflare Pages، أو استضافة عادية). لا يحتاج بناءً ولا خادماً.
للتجربة محلياً: `python3 -m http.server 8000` ثم افتح `http://localhost:8000`.

## الرفع على bawsala.unaux.com
1. من لوحة الاستضافة (File Manager) ادخل مجلد `htdocs` (أو `public_html`).
2. احذف ملف `index2.html` الافتراضي إن وُجد، ثم ارفع **محتويات** هذا المجلد (وليس المجلد نفسه) كما هي، بما فيها `.htaccess`.
3. افتح `https://karrarkoqw4v-ux.github.io/Karrar/` وتأكد أن الصفحة تظهر بالتصميم الداكن.
* ملفات الإعداد الجاهزة: `sitemap.xml` و`robots.txt` و`404.html` و`.htaccess`، وكل الصفحات فيها وسم canonical للدومين.
* بوابة التحميل تعمل على http العادي (لا تعتمد على WebCrypto). فعّل شهادة SSL المجانية من لوحة الاستضافة ثم بدّل `http://` إلى `https://` في `js/config.js` و`sitemap.xml` و`robots.txt` ووسوم canonical.
* لم يُرفع الموقع من طرفي: لا أملك دخولاً إلى استضافتك ولا أطلب كلمات سر الاستضافة.


## نسخة GitHub Pages
هذا المجلد (`docs/` في المستودع) هو نسخة الموقع المهيّأة لـ GitHub Pages على العنوان `https://karrarkoqw4v-ux.github.io/Karrar/`. فيه `.nojekyll` وكل الروابط نسبية فلا تظهر أخطاء 404 داخل المسار الفرعي `/Karrar/`.
