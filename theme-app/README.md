# صانع الثيمات (Theme Master)

تطبيق أندرويد مستقل، بدون تسجيل دخول. شاشة واحدة بزرّين:
- **رفع ملف ثيم (ZIP)** → يُطبَّق فوراً.
- **تصدير الثيم الحالي** → يحفظ خلفيتك الآن كملف ZIP في مجلّد التنزيلات.

## صراحةً: ما الذي يُطبَّق فعلاً، وما الذي لا يمكن لأي تطبيق تطبيقه
لا يستطيع أي تطبيق خارجي — هذا ولا غيره — الوصول إلى محرّك الثيمات الخاص بشاومي (MIUI) أو هواوي/هونر (EMUI/Magic UI). تلك المحرّكات تتحقّق من توقيع الملف (`.mtz` وليس `.zip`) بشهادة الشركة نفسها، ولا يملك أي تطبيق مستقل صلاحية تجاوز ذلك — ولا حتى عبر Shizuku، لأن المشكلة توقيع وليست صلاحية.

**ما يُطبَّق هنا حقيقي 100% ويعمل على كل الأجهزة** عبر `WallpaperManager` (واجهة أندرويد العامة):
- خلفية الشاشة الرئيسية.
- خلفية شاشة القفل (أندرويد 7+).

## تركيب ملف الثيم (ZIP)
```
wallpaper.jpg      ← خلفية الشاشة الرئيسية (اختياري)
lockscreen.jpg     ← خلفية شاشة القفل (اختياري)
theme.json         ← {"name": "اسم الثيم", "author": "..."} (اختياري)
```
يُطبَّق ما هو موجود فقط، ويعرض التطبيق بعد التطبيق ما نجح فعلاً.

## الأمان
فكّ الـZIP محمي من Zip Slip (لا يسمح بأي مسار يخرج عن مجلّد فكّ الملفات)، وله حدّ أقصى للحجم (80MB) ولعدد الملفات (200) لمنع إنهاك الذاكرة.

## البناء
`.github/workflows/theme-app-apk.yml` يبني APK وينشره كإصدار قابل للتحميل عند الدفع إلى `main`.
