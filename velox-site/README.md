# موقع Velox

واجهة موقع/تطبيق جوال بنفس تصميم البوت، مع خادم صغير يربط الموقع بقاعدة بيانات البوت `velox.db`.

## محتويات الملف

```
index.html … (33 صفحة)   صفحات الموقع (HTML)
css/velox.css            الأيقونات (SVG بالـ mask)
css/m.css                التصميم والحركات والأزرار
css/site.css             ضبط العرض والتنبيهات
js/app.js                منطق الواجهة: تسجيل الدخول، إنشاء حساب، ربط البوت، الخروج، Google
js/config.js             إعدادات الواجهة (عنوان الخادم، Google Client ID)
assets/emoji/            إيموجيات تيليجرام المتحركة (WebP)
assets/brands/           أيقونات المنصات الرسمية (SVG)
assets/icon*.{svg,png}   أيقونة التطبيق الرسمية
manifest.json            يجعل الموقع قابلاً للتثبيت كتطبيق على الجوال
server/server.py         الخادم (Flask) + تسجيل الدخول والحسابات
server/bot_link_handler.py  معالج يُضاف إلى main.py لربط الحساب بالبوت
server/requirements.txt  المكتبات
```

## التشغيل السريع (وضع تجريبي بدون خادم)

افتح مجلد الموقع بأي خادم ملفات ثابتة:

```
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. بدون خادم الـ API يعمل الموقع بوضع تجريبي
(أي أيدي وكلمة سر تدخل، والبيانات وهمية) لمعاينة التصميم فقط.

## التشغيل الحقيقي (مرتبط بالبوت)

1. ضع مجلد `velox-site` بجانب ملف البوت `main.py` و`velox.db` على الاستضافة نفسها.
2. ```
   cd velox-site/server
   pip install -r requirements.txt
   SECRET_KEY="اكتب-نصاً-طويلاً-عشوائياً" python server.py
   ```
   الخادم يخدم الصفحات والـ API على المنفذ 8080 (غيّره بـ `PORT`).
3. أضف محتوى `server/bot_link_handler.py` إلى `main.py` قبل أي معالج نصوص عام، وأعد تشغيل البوت.
   هذا ما يجعل البوت يؤكد كود الربط الذي يظهر للمستخدم في الموقع.

عند أول تشغيل يضيف الخادم تلقائياً إلى جدول `users` الأعمدة:
`web_password_hash, web_email, web_google_id, web_name, web_linked`
وينشئ جدول `web_link_codes`. لا يغيّر أي بيانات موجودة للبوت.

### متغيرات البيئة

| المتغير | المعنى |
|---|---|
| `VELOX_DB` | مسار velox.db (الافتراضي: المجلد الأب للموقع) |
| `SECRET_KEY` | مفتاح توقيع الجلسات (إلزامي في الإنتاج) |
| `ADMIN_IDS` | أيديات المسؤولين مفصولة بفاصلة (الافتراضي 8010837412) |
| `GOOGLE_CLIENT_ID` | لتفعيل الدخول بـ Google |
| `PORT` | منفذ الخادم |

## تدفق الحساب

1. **إنشاء حساب:** الاسم + الأيدي + كلمة السر + البريد (اختياري) ← الخادم يخزّن كلمة السر مشفّرة ويعطيك كود `VX-12345`.
2. **ربط البوت:** المستخدم يرسل الكود للبوت `@e6nt2bot` ← المعالج يؤكد الربط.
3. **تسجيل الدخول:** الأيدي + كلمة السر. الحساب غير المربوط يحصل على كود جديد تلقائياً.
4. بعد الدخول تظهر نقاطه ورصيده من نفس قاعدة بيانات البوت.

## الدخول بـ Google

1. أنشئ OAuth Client ID (نوع Web) من Google Cloud Console وأضف دومين موقعك في Authorized JavaScript origins.
2. ضعه في `js/config.js` (`VELOX_GOOGLE_CLIENT_ID`) وفي متغير `GOOGLE_CLIENT_ID` على الخادم.
3. الدخول بـ Google يعمل للحسابات المسجّلة والمربوطة مسبقاً ببريد Google نفسه.

## ما هو جاهز وما هو ليس جاهزاً

**جاهز:** كل صفحات التصميم، التنقل بينها، تسجيل الدخول وإنشاء الحساب وربط البوت والخروج، حماية الصفحات الداخلية،
حماية صفحات المسؤول، التثبيت كتطبيق.

**غير موصول بعد (واجهة فقط):** تنفيذ الطلبات (رشق/ألعاب/تمويل)، الشحن، عجلة الحظ، التحويل، الدعم الذكي، ولوحة المسؤول.
هذه الصفحات تعرض التصميم ببيانات تجريبية، وكل واحدة تحتاج نقطة API تستدعي منطق البوت نفسه.
