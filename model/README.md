# نموذج «بوصلة» (Bawsala-LM) — مجموعة أدوات التدريب

> **صدق تقني:** لا يمكن «تدريب نموذج مثل GPT من الصفر» بجهاز أو حساب عادي. نماذج بهذا المستوى تحتاج آلاف وحدات GPU وأشهراً وبيانات بحجم تريليونات الكلمات وكلفة بملايين الدولارات.
> الطريقة العملية التي تعمل فعلاً (وتستخدمها الشركات الصغيرة): **ضبط دقيق (Fine-tuning)** لنموذج مفتوح المصدر قوي جاهز، ببياناتك أنت، فيصبح «نموذج بوصلة» يتكلم بلهجتك ويتبع أسلوبك.

## ما في هذا المجلد
| الملف | الوظيفة |
|---|---|
| `data/iraqi_seed.jsonl` | عيّنة بذرة من حوارات بالعراقي (للبدء فقط، تحتاج توسيعها إلى آلاف الأمثلة) |
| `train_lora.py` | سكربت ضبط دقيق (LoRA/QLoRA) بمكتبات TRL وPEFT |
| `export_gguf.md` | دمج الأوزان وتحويلها لتشغيلها على الجوال/الخادم |
| `serve/docker-compose.yml` | خادم متوافق مع OpenAI API (vLLM) ليتصل به التطبيق |
| `Modelfile` | تعريف النموذج لـ Ollama (للتشغيل المحلي) |

## الخطوات
1. **اختر نموذجاً أساسياً** (يحدد قدراتك):
   - نص/برمجة/كتابة: `Qwen/Qwen2.5-7B-Instruct` أو `meta-llama/Llama-3.1-8B-Instruct`.
   - صور (قراءة الصور): `Qwen/Qwen2-VL-7B-Instruct` (رؤية + نص). الفيديو يُعالج كإطارات متتابعة.
   - ملفات: يقرأها التطبيق ويحوّلها لنص قبل الإرسال (موجود في تطبيق بوصلة).
2. **ابنِ بياناتك:** حوارات حقيقية بالعراقي (سؤال/جواب)، أمثلة برمجة، أمثلة كتابة. كل سطر في `jsonl` بصيغة `{"messages":[{"role":"user","content":"…"},{"role":"assistant","content":"…"}]}`. الجودة أهم من العدد؛ ابدأ بـ 2–5 آلاف مثال نظيف ثم زد.
3. **درّب على GPU مستأجرة أو مجانية:** Kaggle (T4×2) أو Google Colab أو RunPod/Vast (≈ 0.3–1$ للساعة):
   ```bash
   pip install -U torch transformers trl peft datasets bitsandbytes accelerate
   python train_lora.py --base Qwen/Qwen2.5-7B-Instruct --data data/iraqi_seed.jsonl --out out/bawsala-lora
   ```
4. **ادمج وصدّر** (`export_gguf.md`) ثم **شغّله كخادم** (`serve/`).
5. **اربطه بالتطبيق:** في إعدادات بوصلة ← النماذج: الرابط `https://خادمك/v1` واسم النموذج `bawsala`. التطبيق يتكلم بصيغة OpenAI فيعمل مباشرة.

## ما الذي تتوقعه واقعياً
- يتعلم **الأسلوب واللهجة والصياغة** بسرعة، وهذا ما يحقق «يرد مثل العراقيين».
- لا تتحسن **المعرفة والاستدلال** كثيراً من الضبط الصغير؛ تأتي من النموذج الأساسي.
- لن يطابق GPT-5 أو Claude. لكن نموذجاً 7–14B مضبوطاً جيداً قد يكون ممتازاً لمهامك الضيقة.
- لا أضمن نتائج قبل أن تُجرَّب على GPU؛ لم أشغّل التدريب هنا (لا GPU ولا إنترنت).
