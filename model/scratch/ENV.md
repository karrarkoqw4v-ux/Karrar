# بيئة بوصلة LM الكاملة

```
 نصوص عربية + كود 25 لغة ──► توكنايزر ──► تدريب أولي ──► تعليم المحادثة ──► serve.py (API) ◄── تطبيق بوصلة
        (missions)                         (train.py)       (sft.py)                │
                                                                                     ▼
                         ◄── تعلّم بالاختبار (eval_code.py): يشغّل الكود الذي كتبه النموذج ويحفظ الناجح فقط ◄──┘
```
## الأوامر (`make help`)
`setup → data → tokenizer → prep → train → chat-data → sft → serve → learn → cycle` (كرّر learn/cycle لتحسين البرمجة).

## ما الذي يعمل فعلاً وما الذي لا يعمل بعد
| الجزء | الحالة |
|---|---|
| خادم API متوافق مع OpenAI (`serve.py`) | **اختُبر محلياً** بنموذج تجريبي صغير: `/v1/models` والمفتاح والرد العادي والبث |
| حلقة التعلّم بالاختبار (`eval_code.py`) | **اختُبرت**: الحل الصحيح ينجح، والخطأ والحلقة اللانهائية يفشلان. تغطي **بايثون وجافاسكربت فقط** (8 مهام) |
| إعداد الكود كمستندات كاملة (`prep_data.py --code`) | كُتب وفُحص بناء الجملة؛ لم يُجرَّب على بيانات كود حقيقية |
| جمع الكود بـ25 لغة (`missions/code_languages.json`) | **لم يُجرَّب** (لا إنترنت هنا). أسماء المجلدات في `the-stack-smol` يجب أن تتحقق منها؛ المهمة الفاشلة تُسجَّل وتُتخطى ولا توقف الباقي |
| التدريب الحقيقي | **لم يحدث**: يحتاج GPU وأياماً. حتى ينتهي لن يجيب النموذج جيداً |

## حدود يجب أن تعرفها
- «يتعلم كل اللغات البرمجية»: النموذج يرى أمثلة من 25 لغة، لكن **إتقانه** يعتمد على حجمه. نموذج 110 مليون يكتب مقاطع بسيطة فقط، **اختبار التنفيذ متاح لبايثون وجافاسكربت فقط** حالياً؛ تُضاف لغات أخرى بإضافة مهام في `evals/tasks.jsonl` وسطر في `RUN` داخل `eval_code.py` (المترجم لازم يكون مثبّتاً).
- «يتعلم لوحده»: التعلّم يحدث حين **تشغّل** `make learn` ثم `make cycle`. لا يتغيّر النموذج وحده أثناء المحادثة، ولا يتعلم من محادثات الناس.
- شغّل الكود الذي يولّده النموذج داخل Docker فقط إذا كان النموذج غير موثوق.

## ربطه بالتطبيق
شغّل `make serve` ثم في الإعدادات اختر المزوّد **Bawsala LM (my server)** وضع عنوان جهازك، والمفتاح = `BAWSALA_KEY`. الجوال والحاسوب على نفس الشبكة (أو استخدم نفقاً آمناً).
