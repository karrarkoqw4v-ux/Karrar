# مشروع «بوصلة LM»: تدريب نموذج لغوي من الصفر

هذا مشروع تعليمي وتدريبي كامل: توكنايزر وبيانات ونموذج Transformer وتدريب وتوليد، مع واجهة **Studio** بنفس هوية تطبيق بوصلة لمتابعة كل شيء.

> **صدق:** الكود هنا اختُبر على **عيّنة صغيرة جداً على CPU** للتأكد أنه يعمل (انظر `studio/metrics.json`). لم يُدرَّب نموذج حقيقي (لا GPU عندي ولا بيانات 2 مليار توكن). التدريب الفعلي تشغّله أنت على GPU.

## الأحجام
| الإعداد | المعاملات | المحتوى | العتاد |
|---|---|---|---|
| `tiny` | ≈ 1 مليون | اختبار الكود | CPU |
| `small` | ≈ 110 مليون | **مناسب لـ2 مليار توكن** (قاعدة 20 توكن لكل معامل) | Kaggle T4/P100 أو A100 |
| `b1` | ≈ 1.2 مليار | يحتاج 20 مليار توكن ليكون مجدياً | A100/H100 بذاكرة 40-80GB |

> مع 2 مليار توكن فقط، النموذج **الملائم هو `small`** (110M). تدريب `b1` على 2 مليار توكن يهدر الكلفة وينتج نموذجاً ضعيفاً.

## الخطوات
```bash
pip install -r requirements.txt
# 1) ضع نصوصك المسموحة في data/raw/*.txt  (انظر data/sources.md)
python tokenizer_train.py --input data/raw --vocab 32000
python prep_data.py --input data/raw --target-tokens 2000000000
python train.py --preset small --max-steps 20000 --batch 8 --grad-accum 16 --lr 6e-4
python generate.py --prompt "بوصلة"
```
عدد الخطوات: توكنات الخطوة = `batch × grad_accum × ctx` (مثلاً 8×16×1024 ≈ 131 ألف). لـ2 مليار توكن تلزم نحو 15 ألف خطوة.

## Studio (الواجهة)
افتح `studio/index.html` عبر خادم محلي (`python -m http.server` من مجلد `studio/`) فتقرأ `metrics.json` الذي يكتبه `train.py` أثناء التدريب. فيها: **التعليم** (دروس عربية) و**البيانات** و**التدريب** (منحنى الخسارة) و**التجربة**.

## ما بعد التدريب
نموذج مُدرَّب على نص عام **لا يجيب كمساعد**. للمحادثة: ضبط دقيق على حوارات (`<|user|>` / `<|assistant|>`) في مرحلة ثانية. الرموز الخاصة جاهزة في التوكنايزر.
