# بوصلة AI — بيئة مقسّمة (150+ ملف)

كل ملف هنا له **شغلة واحدة محدّدة**: تدريب، أو رد، أو برمجة، أو تصميم، أو مستودع. هذا تنظيم حقيقي للعمل، وليس تدريباً جاهزاً لنموذج.

> **صدق قبل كل شيء:** هذا المجلد يحتوي **كوداً وبيانات تأسيسية وأدوات**، لا نموذجاً مدرَّباً. جودة الردود النهائية تعتمد على تدريب فعلي على GPU (أسابيع، بيانات بمليارات التوكنات)، وهذا لا يحدث من هذه الجلسة. ما بُني هنا هو **البنية التحتية** الصحيحة لذلك، مقسّمة بعناية بدل ملف واحد ضخم، بحيث أي تدريب تسويه لاحقاً (بنفسك أو بطلب مني) يكون منظّماً ومتخصصاً.

**المجموع:** 181 ملفاً (أكثر من 150). كل رقم أعلاه حقيقي (`find . -type f` بعد حذف ملفات `__pycache__`)،
وكل الاختبارات في `tests/` **نُفِّذت فعلاً** قبل كتابة هذا الملف (`python3 tests/run_all.py` → 13 نجح، 0 فشل).

## الاستخدام السريع
```bash
cd model/bawsala-ai
pip install -r config/requirements.txt
python tests/run_all.py            # يتحقق أن كل الوحدات تعمل (بدون تدريب حقيقي)
python train/01_tokenizer.py --input data/wiki data/code data/dialects
python train/02_pretrain.py --preset small --resume
python train/03_sft_chat.py
python serve/api_server.py
```
