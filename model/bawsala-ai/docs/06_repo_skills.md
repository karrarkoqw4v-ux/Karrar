# مهارة إدارة المستودعات (skills/repo/)

8 ملفات، كل واحد يصف أداة حول git: `status`، `diff_summary`، `commit_message`، `branch_check`،
`secret_scan`، `changelog`، `pr_description`، `safety_gate`.

**مبدأ أساسي:** هذه الملفات **تصف** ما يجب فعله، ولا **تنفّذ** أوامر git خطيرة بنفسها. `safety_gate`
تحديداً يمثّل قاعدة صريحة: أي أمر مثل `push --force` على الفرع الرئيسي أو `reset --hard` يُمنع دون تأكيد
صريح من الإنسان، بغضّ النظر عمّن يطلبه (نموذج أو وكيل). هذا يطابق قاعدة "لا حذف دون نظر، لا دمج بدون إذن"
المتّبعة في بقية هذا المشروع.
