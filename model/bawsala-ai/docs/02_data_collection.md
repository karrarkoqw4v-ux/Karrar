# جمع البيانات (data/)

ثلاثة مصادر منظّمة بسياسة واحدة في `config/policy.py`:

## 1) `data/wiki/` — نصوص عربية عامة
ويكيبيديا وويكي كتب ومصادر وقاموس ويكيميديا، كلها CC BY-SA 4.0 (تلزم ذكر المصدر عند إعادة النشر).

## 2) `data/code/` — كود مصدري، 26 لغة
ملف منفصل لكل لغة (بايثون، جافاسكربت، تايبسكربت، جافا، C، ++C، #C، Go، Rust، PHP، Swift، Kotlin، Ruby، Dart،
SQL، HTML، CSS، Shell، Lua، R، Scala، Haskell، Perl، PowerShell، Assembly، PL/SQL). كل ملف يصف **مهمة** (مصدر
+ ترخيص + حد توكنات) لا يجلب شيئاً بنفسه إلا عبر `train/06_data_missions.py`. الكود يُحفظ كمستندات كاملة
(مفصولة بـ`<|doc|>`) وليس أسطراً مبعثرة، لأن قطع دالة في المنتصف يفسد تعلّم بنيتها.

## 3) `data/web/` — صفحات ويب يضيفها المستخدم بنفسه
**لا زحف عشوائي أبداً.** فقط الروابط التي تضعها في `urls.txt`. قبل أي طلب:
1. `https` فقط (`config/policy.py: ALLOWED_SCHEMES`).
2. رفض فوري للمنصات المحظورة (`BLOCKED_PLATFORMS`: يوتيوب، تيك توك، إنستغرام، فيسبوك، X...).
3. احترام `robots.txt` (`data/web/robots.py`).
4. تأخير بين الطلبات (`REQUEST_DELAY_SEC`)، وحد أقصى للصفحات (`MAX_PAGES_PER_RUN`).
5. رفض أي إعادة توجيه لنطاق مختلف.

كل هذه القواعد **مُختبرة فعلياً** في `tests/test_web_fetch.py` و`tests/test_policy.py`، وليست تعليقاً فقط.
