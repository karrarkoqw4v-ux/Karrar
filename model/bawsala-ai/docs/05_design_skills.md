# مهارة التصميم (skills/design/)

12 ملفاً، كل واحد يصف نوع صفحة ويب شائعاً وبنيته المتوقعة: صفحة هبوط، لوحة تحكم، دخول، مقال مدوّنة،
بطاقة منتج، أسعار، تواصل، معرض أعمال، أسئلة شائعة، خطأ 404، دفع، إعدادات.

كل ملف يحتوي `SYSTEM_PROMPT_ADDON`: جملة إضافية تُدمج في تعليمات النموذج عند طلب هذا النوع تحديداً، لتوجيهه
نحو البنية الصحيحة (مثلاً: لوحة التحكم تحتاج شريطاً جانبياً وبطاقات إحصائيات، لا نفس بنية صفحة الهبوط).

هذا نفس المبدأ المستخدم في وكيل بوصلة الحالي (أمر `/ابنِ`): توليد → اختبار فعلي في متصفح معزول → تصحيح →
تسليم، وليس توليداً واحداً بلا تحقق.
