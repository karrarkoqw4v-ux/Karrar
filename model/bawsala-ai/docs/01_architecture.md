# بنية النموذج (core/)

نموذج Transformer بسيط من نوع فك-تشفير فقط (decoder-only)، يشبه بنية GPT/LLaMA الصغيرة:

```
مدخل الكلمات → تضمين (Embedding) → [طبقة Transformer] × n_layer → تطبيع → طبقة خرج → احتمالات الكلمة التالية
```

كل طبقة Transformer (`core/block.py`):
```
x → RMSNorm → انتباه ذاتي (مع RoPE) → + x (اتصال متبقٍ)
  → RMSNorm → SwiGLU MLP → + (اتصال متبقٍ)
```

## الأحجام (core/config.py)
| الاسم | المعاملات | العتاد المناسب |
|---|---|---|
| `tiny` | ~1 مليون | اختبار الكود على CPU فقط |
| `small` | ~110 مليون | GPU مجاني (T4/P100)، يحتاج ~2 مليار توكن |
| `b1` | ~1.2 مليار | GPU بذاكرة 40-80GB، يحتاج ~20 مليار توكن |

## لماذا هذه الخيارات التقنية تحديداً
- **RoPE** بدل جدول مواضع ثابت: يعمم أفضل على نصوص أطول مما رآه التدريب.
- **RMSNorm** بدل LayerNorm: حسابات أقل، استقرار مكافئ تقريباً.
- **SwiGLU** بدل ReLU/GELU: أثبتت تجريبياً (في LLaMA وPaLM) جودة أعلى بنفس عدد المعاملات.
- **تضمين مربوط (tied embeddings)**: طبقة الدخول والخرج تشتركان بنفس الأوزان، يوفّر ذاكرة.
