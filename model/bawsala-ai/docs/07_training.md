# التدريب (train/)

ترتيب المراحل (كل واحدة ملف مستقل قابل للتشغيل بمفرده):

```
01_tokenizer.py       → توكنايزر BPE من كل النصوص المجموعة
02_prep_data.py       → تنظيف + توكنة + ملفات train.bin/val.bin
       (يُشغَّل مرتين: مرة للنص العام، ومرة --code --append للكود)
03_pretrain.py        → التدريب الأولي (معرفة عامة)، قابل للاستئناف --resume
04_build_sft.py       → يبني out/chat.jsonl من data/qa + data/dialects + ملفاتك
05_sft.py             → يعلّم المحادثة (الخسارة على كلام المساعد فقط)
06_data_missions.py   → ينفّذ كل مهمات جمع البيانات (استدعاء مساعد لـ02)
07_eval_code.py        → تعلّم بالاختبار: كود يُنفَّذ فعلاً، الناجح فقط يُحفَظ
08_eval_chat.py        → تقييم تقريبي لجودة الرد العام
09_cli_generate.py    → تجربة سريعة من نقطة تفتيش
10_pipeline.py         → يشغّل 01→05 بأمر واحد (للتجربة فقط، ليس للتدريب الحقيقي)
```

## اختُبر فعلياً هنا
المسار الكامل (01 → 02 → 03 → 04 → 05) على نص اصطناعي صغير بحجم `tiny`، على معالج (CPU)، بلا GPU:
يعمل بلا أخطاء من أول مرة بعد إصلاح خطأين وُجدا أثناء الاختبار (استيراد خاطئ للّهجات، وحجم بيانات صغير
جداً لسياق النموذج). النتائج هراء كما هو متوقع من 10-60 خطوة تدريب فقط؛ الهدف كان التحقق من الكود لا الجودة.

## لم يُختبر
التدريب الحقيقي على GPU بحجم `small` أو `b1`، لأن هذه البيئة لا تملك GPU ولا وصولاً لبيانات بمليارات التوكنات.
