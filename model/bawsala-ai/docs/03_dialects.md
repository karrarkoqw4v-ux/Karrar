# اللهجات (data/dialects/)

28 ملفاً، كل واحد يمثّل لهجة أو لغة: العراقية، السورية، اليمنية، السعودية، الكويتية، الإماراتية، القطرية،
البحرينية، العُمانية، المصرية، اللبنانية، الأردنية، الفلسطينية، المغربية، الجزائرية، التونسية، الليبية،
السودانية، الفصحى، الحجازية، النجدية، الخليجية العامة، الشامية العامة، المغاربية العامة، التشادية،
الصومالية (متحدثو العربية)، الموريتانية (الحسانية)، والإنجليزية العامة.

كل ملف فيه:
- `MARKER_WORDS`: كلمات تدل على اللهجة (لاكتشافها تلقائياً من كلام المستخدم، دالة `detect()`).
- `SAMPLE_GREETING`: جملة ترحيب بأسلوب هذه اللهجة، تُستخدم كبذرة تدريب في `train/04_build_sft.py`.

**صدق مهم:** هذه عيّنة واحدة لكل لهجة، كافية لإعطاء النموذج *إحساساً* بالأسلوب، وليست كافية لإتقانه.
لتعليم لهجة فعلياً تحتاج مئات أو آلاف الأمثلة الحقيقية بها (ضعها في `data/qa/mine/`).
