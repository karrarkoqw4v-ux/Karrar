# وكيل حساب «بوصلة» على تيك توك (يعمل بالطريقة الرسمية)

> **غير مُجرَّب:** كتبتُ هذا دون القدرة على تشغيله (لا إنترنت ولا مفاتيح تيك توك في بيئتي). يلزم تجربته عندك.

## ما يفعله الوكيل
1. **`plan`**: يقرأ أسئلة المتابعين من `questions.txt` ويطلب من نموذجك (أي واجهة متوافقة مع OpenAI) كتابة سكربت بصيغة «أنا بوصلة» + وصف + هاشتاقات، ويحفظها في `out/`.
2. **`auth-url` ثم `exchange`**: تسجيل دخول رسمي (OAuth) **أنت** من توافق عليه داخل تيك توك، ولا يُطلب منه كلمة سرك أبداً. الرمز يُحفظ محلياً في `tokens.json` (محجوب من Git).
3. **`draft`**: يرفع ملف الفيديو الذي صنعتَه إلى **مسودات حسابك** (Upload API). تفتح تيك توك فيصلك إشعار، تراجع الفيديو وتضغط **نشر** بنفسك. لا ينشر الوكيل من تلقائه.

## لماذا مسودة وليس نشراً مباشراً
- النشر المباشر (Direct Post) يحتاج تدقيق تطبيقك من تيك توك، وقبله تُنشر الفيديوهات خاصة فقط.
- بقاء الإنسان في الحلقة يحميك من محتوى خاطئ أو مخالف، ومن الحظر.
- **ضع وسم «محتوى مُنشأ بالذكاء الاصطناعي»** عند النشر (مطلوب من تيك توك).

## ما لا يفعله (ولن أبنيه)
- لا يسجّل دخولاً بكلمة سر، ولا يتحكم بالحساب عبر محاكاة المتصفح. هذا مخالف لشروط تيك توك ويعرّض الحساب للحظر، ويتطلب إرسال كلمة سرك إلى كود.
- لا يرد على التعليقات آلياً ولا يتابع ولا يعجب (سلوك آلي يُعدّ سبام).

## التجهيز (مرة واحدة)
1. سجّل تطبيقاً في [developers.tiktok.com](https://developers.tiktok.com) وفعّل منتج **Content Posting API** بصلاحية `video.upload`، وأضف رابط إعادة التوجيه `http://localhost:8080/callback`.
2. أضف حسابك كـ **Target user** (وضع الاختبار) إلى أن يُقبل تطبيقك.
3. ضع المفاتيح في متغيرات بيئة (لا في ملفات):
```bash
export TIKTOK_CLIENT_KEY=...  TIKTOK_CLIENT_SECRET=...
export LLM_BASE_URL=https://api.groq.com/openai/v1  LLM_API_KEY=...  LLM_MODEL=llama-3.3-70b-versatile
pip install requests
```

## الاستخدام
```bash
python agent.py plan                       # يكتب سكربتات من questions.txt إلى out/
python agent.py auth-url                   # افتح الرابط ووافق، ثم انسخ code من عنوان الصفحة
python agent.py exchange <code>
python agent.py draft video.mp4            # يرفع إلى مسودات حسابك
```
