# ⚡ مسرّع الألعاب (Game Booster)

تطبيق أندرويد مستقل (مشروع منفصل عن بوصلة) يهيّئ الجهاز قبل اللعب.

## ماذا يفعل
- يكتشف الألعاب المثبّتة تلقائياً (ويمكنك إضافة أي تطبيق كلعبة بالضغط المطوّل).
- عند الضغط على لعبة: يغلق عمليات الخلفية للتطبيقات غير النظامية، يفعّل «عدم الإزعاج» (اختياري)، ثم يشغّل اللعبة.
- يعرض الذاكرة الحرّة والبطارية والحرارة مع تنبيه عند السخونة.

## ملاحظة صريحة
أندرويد لا يسمح لتطبيق عادي برفع سرعة المعالج أو الـFPS؛ التسريع هنا يعني تحرير الذاكرة وتقليل المقاطعات.

## البناء
`cd game-booster && gradle assembleRelease` (يحتاج Android SDK)، أو عبر GitHub Actions: `.github/workflows/game-booster-apk.yml`.
