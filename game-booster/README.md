# ⚡ مسرّع الألعاب (Game Booster)

تطبيق أندرويد مستقل (منفصل عن بوصلة)، وضع أفقي بملء الشاشة.

## مسار التطبيق
0. **بوابة Shizuku**: لا يدخل التطبيق قبل تثبيت Shizuku وتشغيله ومنح الإذن (يوجد رابط صغير «متابعة بدون Shizuku» لهذه الجلسة فقط، بميزات أقل).
1. **مقدمة حيّة**: سيارة سريعة ← انفجار ضوء ← شعار + اسم + شارات، وزر «تسريع الآن» يظهر من أول لحظة ويبقى.
2. **الضغط على الزر** ← شاشة **الصلاحيات** (تُتجاوز إن كانت ممنوحة كلها).
3. **لوحة الخيارات (Hub)**: عدّادات الذاكرة والحرارة + أدوات التسريع.

## الصلاحيات
| الصلاحية | لماذا | كيف تُمنح |
|---|---|---|
| عدم الإزعاج (Notification Policy) | كتم الإشعارات والمكالمات | شاشة إعدادات النظام |
| الظهور فوق التطبيقات | الفقاعة العائمة فوق اللعبة | شاشة إعدادات النظام |
| قراءة التطبيقات المثبّتة | عرض الألعاب وتشغيلها | تلقائي عند التثبيت |
| إغلاق تطبيقات الخلفية | تحرير الذاكرة | تلقائي عند التثبيت |
| الإشعارات (أندرويد 13+) | تشغيل الفقاعة في الخلفية | نافذة النظام |
| تعديل إعدادات النظام (اختياري) | رفع السطوع | شاشة إعدادات النظام |

## الأدوات
تسريع كامل بضغطة، تنظيف الخلفية، كتم الإشعارات والمكالمات، وضع صوت الألعاب + شريط مستوى الصوت، سطوع أعلى، فقاعة عائمة (تنظيف / كتم / صوت)، مكتبة الألعاب، لوحة الإنترنت، الصلاحيات.

## ملاحظة صريحة
أندرويد لا يسمح لتطبيق عادي برفع سرعة المعالج أو الـFPS؛ «التسريع» = تحرير ذاكرة + تقليل المقاطعات + ضبط الصوت والسطوع.

## البناء
`.github/workflows/game-booster-apk.yml` يبني APK على GitHub (أو `gradle assembleRelease` مع Android SDK).

## ما الذي يعمل عبر Shizuku (حقيقي، يُنفَّذ بصلاحيات shell)
- وضع الأداء للعبة (`cmd game mode`)، أداء ثابت (`cmd power set-fixed-performance-mode-enabled`)، تنظيف كاش كل التطبيقات (`pm trim-caches`)، إغلاق قسري (`am force-stop`)، لمس أسرع (`settings put secure long_press_timeout`).
- لقطة شاشة (`screencap`) تُحفظ في `Pictures/GameBooster`.
- قراءة استهلاك المعالج من `/proc/stat` واستهلاك الـGPU إن وفّره الجهاز.
بعض الأوامر تعتمد على دعم الجهاز/إصدار أندرويد، والتطبيق يعرض نتيجة الأمر الفعلية.

## اللوحة فوق اللعبة
بعد «بدء اللعب» يظهر لسان مضيء على حافتي الشاشة؛ اسحبه للداخل لتفتح لوحتين بعدّادات حيّة (معالج/ذاكرة/حرارة/بطارية) وأدوات (لقطة، عدم الإزعاج، سطوع، قفل تدوير، تنظيف، وضع الأداء، أداء ثابت، لمس أسرع) وشريطي سطوع وصوت.

## «أداء ثابت» (زر في لوحة اللعبة)
يُنفَّذ بأمر shell واحد خلال ثانية إلى ثانيتين: وضع الأداء الثابت من النظام، Game Mode للّعبة، إغلاق تطبيقات الخلفية (`am kill-all` + إغلاق قسري) وتنظيف الكاش، أعلى معدّل تحديث تدعمه الشاشة فعلاً، ضبط الشبكة (`tcp_default_init_rwnd`، `mobile_data_always_on`)، تسريع الحركات، ولمس أسرع.
- حماية الحرارة: إن بلغت حرارة البطارية 44° يخفّض المعدّل مؤقتاً ثم يرجعه عند 41°.
- عند الخروج من اللعبة يُرجع التطبيق كل القيم تلقائياً ويُغلق اللوحة.
- لا يلمس ملفات اللعبة إطلاقاً؛ يستخدم فقط ميزات النظام وإعداداته.

## عدم الإزعاج
يُبقي صوت اللعبة والوسائط والمنبّهات؛ يكتم الإشعارات (والمكالمات في الوضع الكامل). لا يستخدم «الصمت التام».

## تحديثات: أيقونة + تقطيع الحواف + تحكّم أدق + «أداء ثابت» أقوى
- أيقونة تطبيق حقيقية (adaptive icon) بدل أيقونة أندرويد الافتراضية.
- كل الشاشات واللوحة فوق اللعبة تقرأ الآن حواف الجهاز الفعلية (شريط الحالة، النوتش، الزوايا المستديرة) وتُبعد الأزرار عنها بدل الاعتماد على هامش ثابت.
- شريطا السطوع والصوت صار لهما زرّا +/− بخطوة ~7% بجانب السحب، مع عرض النسبة رقمياً.
- «لون الشاشة» صار 5 مرشّحات واقعية بتدرّج (دافئ سينمائي، بارد حيوي، مشبّع نابض، ليلي) بدل تلوين مسطّح؛ وهي فلاتر شفافة فوق الشاشة فعلاً (SRC_OVER)، وليست معايرة لعتاد الشاشة — هذا حد تقني حقيقي.
- «أداء ثابت» يضيف الآن: الخروج من وضع الخمول القسري (`dumpsys deviceidle unforce`)، إيقاف توفير الطاقة (`low_power 0`)، استثناء اللعبة من تقييد الخلفية (`am set-inactive false`)، وإبقاء الشاشة مضاءة أثناء اللعب (`svc power stayon`، يُرجَع تلقائياً عند الخروج).
- زر «تسريع الآن» في لوحة الأدوات يفعّل «أداء ثابت» تلقائياً إذا كان Shizuku متاحاً.
- الفقاعة/اللوحة لا تظهر فوق واجهة المسرّع نفسه بعد الآن؛ تنتظر حتى تتأكد (عبر Shizuku أو صلاحية الاستخدام) أن اللعبة الخارجية صارت في المقدّمة، أو تظهر بعد مهلة قصيرة كحدّ أقصى.

## ما لم يُنفَّذ، وبقصد
- أي أداة تُخفي التطبيق أو نشاطه عن نظام مكافحة الغش في اللعبة، أو «تشفير» يمنع الشركة من رؤيته: هذا تمويه عن كشف (detection evasion) ولا يُبنى هنا مهما صيغ الطلب.
- عصا تحكّم/واجهة تُرسل ضغطات حقيقية لتحريك اللاعب تلقائياً داخل اللعبة: هذا حقن مدخلات (input injection) يُعامَل كأداة أتمتة/غش ويخالف شروط أي لعبة تنافسية، فلم يُضَف.
