# تطبيق Velox (يعمل بدون خادم)

تطبيق كامل مستقل: لا خادم، لا عنوان، لا إنترنت، ولا علاقة له بالبوت.
أول ما تفتحه تظهر شاشة **إنشاء حساب** أو **لدي حساب بالفعل**.

## كيف يحفظ البيانات

كل الحسابات والرصيد والطلبات والخدمات والأكواد محفوظة في قاعدة بيانات داخل ذاكرة الهاتف (`js/local-db.js`).
تبقى بعد إغلاق التطبيق وإعادة تشغيل الجهاز، وتُحذف فقط إذا مسحت بيانات التطبيق أو حذفته.

> **مهم:** لأن التطبيق بلا خادم، البيانات خاصة بكل هاتف. الحسابات المسجّلة على هاتف لا تظهر على هاتف آخر،
> والخدمات التي يضيفها المطور على هاتفه لا تصل إلى هواتف المستخدمين. لمشاركة البيانات بين الهواتف يلزم خادم.
> يمكن حفظ نسخة احتياطية من لوحة التحكم ونقلها لجهاز آخر (استعادة نسخة).

|---|---|
| الأيدي | `8010837412` |
| اسم المستخدم | `admin` |
| البريد | `admin@velox.app` |
| كلمة السر | `1005` |

## ما يعمل

**المستخدم:** إنشاء حساب برصيد 0، الدخول (باسم المستخدم أو البريد أو الأيدي)، شحن بكود، هدية يومية، تحويل نقاط،
طلب خدمات الرشق والألعاب (يخصم الرصيد)، متابعة الطلبات، تغيير كلمة السر، تعدد الحسابات على نفس الهاتف.

**لوحة المطور:** الخدمات (إضافة/تعديل/إخفاء/حذف)، الطلبات (تغيير الحالة، والرفض يُرجع النقاط)، الحسابات (بحث، رصيد، حظر)،
الأكواد، الإعدادات، النسخ الاحتياطي والاستعادة، تفاصيل التخزين.
التطبيق يبدأ بدون خدمات: أضفها من لوحة التحكم.
