# تطبيق Velox (مستقل عن البوت)

تطبيق كامل بحساباته ورصيده الخاص. لا علاقة له بالبوت ولا بقاعدة بياناته.
أي مستخدم ينشئ حسابه من التطبيق ويبدأ برصيد 0، والمطور يدير كل شيء من لوحة التحكم داخل التطبيق.

## المكونات

| الملف | الوظيفة |
|---|---|
| `velox.apk` | تطبيق الأندرويد |
| `server/velox_app_server.py` | خادم التطبيق (ملف واحد، بدون مكتبات، قاعدته الخاصة `velox_app.db`) |
| `*.html` + `css/` + `js/` + `assets/` | واجهة التطبيق (مضمّنة داخل الـ APK) |

## تشغيل الخادم

على أي استضافة أو جهاز فيه Python 3.8 فما فوق:

```
python3 velox_app_server.py
```

- المنفذ الافتراضي 8080 (`PORT=9000` لتغييره). يجب أن يكون مفتوحاً للإنترنت.
- أنشئ ملف القاعدة تلقائياً `velox_app.db` بجانب الملف (`VELOX_APP_DB` لتغيير المسار).
- يمكن تشغيله بالخلفية: `nohup python3 velox_app_server.py > server.log 2>&1 &`

## أول تشغيل للتطبيق

يطلب التطبيق **عنوان الخادم** مرة واحدة، مثل `http://123.45.67.89:8080`، ثم يحفظه.

## حساب المطور

| | |
|---|---|
| الأيدي | `8010837412` |
| اسم المستخدم | `admin` |
| البريد | `admin@velox.app` |
| كلمة السر | `1005` |

تدخل بأيٍّ من الأيدي أو اسم المستخدم أو البريد. غيّر كلمة السر عند التشغيل:
`ADMIN_PASSWORD="كلمة-قوية" python3 velox_app_server.py` (يُحدَّث في كل تشغيل بهذا المتغير).

## ما يعمل (حقيقي)

**المستخدم:** إنشاء حساب (الاسم، اسم المستخدم، كلمة السر، بريد اختياري)، الدخول، رصيد خاص يبدأ من 0،
شحن الرصيد بكود، هدية يومية، تحويل نقاط بين المستخدمين، طلب خدمات الرشق والألعاب (يخصم الرصيد)، متابعة الطلبات وتتبعها،
تغيير كلمة السر.

**المطور (لوحة التحكم):** إضافة وتعديل وإخفاء وحذف الخدمات (الرشق والألعاب)، إدارة الطلبات وتغيير حالتها
(الرفض يُرجع النقاط تلقائياً)، الحسابات (بحث، إضافة/خصم/تصفير الرصيد، حظر)، أكواد الشحن، إعدادات التطبيق
(الاسم، الهدية اليومية، رابط الدعم، القناة، نص الشحن، إغلاق التسجيل)، نسخة احتياطية للقاعدة، تفاصيل الخادم.

## ملاحظات

- التطبيق يبدأ **بدون أي خدمات**: أضفها من لوحة التحكم ← خدمات الرشق / الألعاب.
- الطلبات تُسجَّل وتُدار من لوحة التحكم، والتنفيذ الفعلي عند المطور يدوياً (لا يوجد ربط مع مواقع رشق خارجية).
- لا توجد بوابة دفع: الشحن بالأكواد التي ينشئها المطور أو بتحويل نقاط.
- الدخول بحساب Google غير موجود (يحتاج مفتاح Google ومكتبة أندرويد خاصة).
