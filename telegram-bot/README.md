# بوت بوصلة على تيليجرام

نفس شخصية مساعد بوصلة، بايثون، للنشر على سيرفر VPS يبقى يشتغل دائماً. **اختُبر فعلياً**: توكن البوت حقيقي
وتحقّقتُ منه مباشرة (`getMe` نجح، البوت اسمه `@Bawsala_aibot`)، ونجح `setMyCommands` أيضاً. منطق البرنامج
(استخراج الإيموجي المميز، فصل الأدمن عن المستخدم) له 8 اختبارات وحدة تمر كلها (`pytest tests/`)، بما فيها
اختبار لعلّة حقيقية لقيتها وأصلحتها أثناء البناء (راجع «صدق» تحت).

## الإعداد
```bash
cp .env.example .env
nano .env   # ضع BOT_TOKEN (موجود أصلاً أدناه) ومفتاح نموذج ذكاء (AI_API_KEY) من Groq مثلاً
pip install -r requirements.txt python-dotenv
python bot.py
```

## النشر الدائم على VPS
**بـ Docker (مفضّل):**
```bash
docker compose up -d --build
```
**أو بـ systemd (بدون Docker):**
```bash
sudo cp bawsala-bot.service /etc/systemd/system/
sudo systemctl enable --now bawsala-bot
```
كلا الطريقتين تعيد تشغيل البوت تلقائياً عند أي عطل أو إعادة إقلاع السيرفر.

## الأدمن (ID: 8010837412)
فقط هذا الحساب يرى لوحة التحكم (`/stats`, `/broadcast`, `/moji`, `/listmoji`). أي شخص آخر يحادث البوت
العادي فقط. لوحة الأدمن نصّ عادي بلا إيموجي مميز عمداً (حتى لا تظهر فارغة أو مشوّهة لمن لا يملك تيليجرام
بريميوم)؛ الإيموجيات المميزة تظهر فقط بردود المستخدمين العاديين.

## الإيموجيات المميزة (Premium/Custom emoji) — كيف تُستخرج فعلياً
**لا يوجد دليل عام لأرقامها، ولا طريقة "أجيبها من فراغ".** الرقم (`custom_emoji_id`) خاص بكل إيموجي ولا
يظهر إلا داخل رسالة حقيقية تحتويه. الطريقة الوحيدة الصحيحة:
1. أرسل أو حوّل (forward) للبوت رسالة فيها إيموجي مميز (من لوحة الإيموجي المميزة بتيليجرام، علامة ⭐).
2. رُدّ على تلك الرسالة بالأمر `/moji اسم_تختاره` (وأنت الأدمن).
3. يحفظه البوت، ويظهر في ردود المستخدمين العاديين بعدها عشوائياً.
كرّرها لأي عدد تريده. `/listmoji` يعرض كل ما حُفظ حتى الآن.

## صدق — ما اختُبر وما لم يُختبر
- ✅ التوكن حقيقي ويعمل (`getMe`, `setMyCommands` نجحا فعلياً).
- ✅ منطق استخراج الإيموجي واختيار الرد: 8 اختبارات تمر، بما فيها حالة كانت تكسر الكود فعلاً (إيموجي عادي
  قبل الإيموجي المميز بالنص يُزيح الفهرسة لأن تيليجرام يحسب المواضع بوحدات UTF-16 لا بمحارف بايثون؛
  أصلحتها قبل التسليم).
- ❌ **لم يُشغَّل بالاستطلاع الحقيقي (polling) لمدة طويلة ولا على سيرفر فعلي** — هذا يحتاج منك تشغيله على
  الـVPS. لو صار خطأ أول تشغيل أرسل لي رسالة الخطأ من السجل (`docker compose logs -f` أو `journalctl -u bawsala-bot -f`).
- ❌ لم يُختبر استدعاء نموذج الذكاء الفعلي (`AI_API_KEY` فارغ هنا)، لأني لا أملك مفتاحك. أضف مفتاحاً مجانياً
  من Groq أو أي مزوّد متوافق مع OpenAI.

## تنبيه أمني
توكن البوت مكتوب بالمحادثة معي، وهذا يعني أنه لم يعد سرّاً تماماً. لو تريد الحيطة، افتح BotFather داخل
تيليجرام واطلب `/revoke` لتوليد توكن جديد، وضع الجديد في `.env` فقط (الملف داخل `.gitignore`، لن يُرفع لأي
مستودع عام من هذا المشروع).

## الحدود المتعمَّدة (لن تُضاف)
- لا تشغيل داخل تطبيق بوصلة (Java/WebView) نفسه؛ بايثون لا يعمل جوّا ذاك التطبيق. هذا مشروع منفصل.
- لا قراءة لإشعارات تطبيقات أخرى، ولا أي صلاحية خارج حدود Telegram Bot API الرسمية.
