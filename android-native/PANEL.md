# تيربو رشق — لوحة التحكم كاملة (مطابقة لبوت التيليجرام)

لغات التطبيق: Kotlin + Jetpack Compose للواجهة، SQLite لقاعدة البيانات، NotificationManager للإشعارات، Telegram Bot API لسحب الإيموجي المميز فقط.

## أقسام لوحة المطور (نفس ترتيب البوت)
1. إدارة خدمات الألعاب — التصنيفات (ببجي، نجوم، نتفلكس، فري فاير، أرقام، اشتراك إجباري، تفعيل مميز، اسياسيل، لودو، اثير، ذهب لودو): إضافة/تعديل (اسم، سعر، كمية، وصف)/إخفاء/حذف + صورة رسمية لكل تصنيف.
2. إدارة خدمات الرشق — المنصات (تيك توك، انستغرام، فيسبوك، يوتيوب، كواي، تليجرام، ثريدز، واتساب، مميزة، تفاعلات تليجرام): اسم، سعر لكل 1000، حد أدنى.
3. إدارة الخدمات المجانية.
4. ربط الموقع الرسمي (روابط، القناة، الدعم).
5. قسم التفعيل والتعطيل: التمويل، تحويل النقاط، أكواد الخصم (مفاتيح تشغيل/إيقاف تؤثر فعلياً).
6. قسم الإعدادات:
   - الكلايش والمتغيرات: اسم التطبيق، العملة، كليشة الشحن، الشروط، التجميع، التمويل، النجوم، رسالة الترحيب.
   - قنوات الإشعارات: قناة إكمال الطلب، رابط بوت الألعاب، رابط بوت الرشق.
   - كلاشات الإشعارات: إكمال الرشق، إكمال الألعاب.
   - قسم التحقق: 6 أرقام / الرقم / تعطيل.
   - إعدادات التمويل: سعر العضو، الحد الأدنى، الحد الأقصى.
7. قسم الاستبدال (قيد التطوير في البوت أيضاً).
8. قسم التمويل.
9. قسم الهدايا: الهدية اليومية، عجلة الحظ (أقل/أعلى)، الأسبوعية، نقاط الدعوة، صنع رابط/كود هدية.
10. قسم النقاط: إضافة، خصم، تصفير، إحصائيات.
11. قسم الحسابات: بحث عن مستخدم (رصيد/حظر)، عدد المستخدمين، حذف كل النقاط، رسالة جماعية.
12. قسم الشحن: تشغيل/إيقاف اسياسيل والنجوم، شحن يدوي، إحصائيات، آخر عمليات الشحن، نصوص الشحن.
13. النسخ الاحتياطية: إنشاء، استعادة، حذف القديمة، تصدير/استيراد ملف.
14. الإحصائيات.
15. تعديل النصوص: نصوص الإشعارات، تفاصيل الرشق، الألعاب/النقاط/الشحن/النجوم، الشروط، كلاشات الإكمال، نص الاشتراك الإجباري (الهاشتاقات #id #first_name #username #points #balance).
16. إدارة الأكواد.
17. الدعم الذكي: ترحيب + أسئلة شائعة (سؤال|جواب) تُطابَق مع كلام المستخدم.
18. الاشتراك الإجباري: قنوات/كروبات/بوتات + نص.
19. تفاصيل التطبيق (بديل «ملفات الاستضافة» و«تفاصيل الخادم»): الإصدار، حجم القاعدة، الأعداد.
إضافات: تعديل الأزرار (الاسم، اللون، الإيموجي المميز، الموضع، إعادة ضبط)، الإيموجي المميز (توكن، معرّف، ملف معرّفات، حزمة)، إذاعة/هدايا/منشورات، الطلبات، المستخدمون.

## حساب المستخدم
معلومات الحساب (الاسم، الهاتف)، تغيير اسم المستخدم، تغيير البريد، تغيير كلمة السر،
الخصوصية (إخفاء الرصيد، تحويل كمجهول، منع استقبال التحويلات، منع الرسائل)،
الإشعارات (تشغيل/إيقاف لكل نوع: تحويلات، هدايا، رسائل، إذاعات، منشورات، طلبات)،
الألوان (لون بطاقة الرصيد، لون فقاعات الرسائل)، الرسائل (إرسال بين المستخدمين باليوزر).

## الإشعارات
تحويل: «وصلك تحويل 💰 — استلمت X من الاسم (@user)»؛ هدية؛ رسالة؛ إذاعة؛ منشور؛ تحديث طلب.
تظهر في شريط الإشعارات بشعار التطبيق ولونه، وداخل التطبيق كفقاعات بإيموجي متحرك حسب النوع.
