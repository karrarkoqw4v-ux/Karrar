# حاسوب سحابي بمحاكي أندرويد يتحكم به الذكاء الاصطناعي

> **غير مُجرَّب:** كتبتُ هذه المجموعة دون القدرة على تشغيلها (لا خادم ولا KVM/GPU ولا إنترنت في بيئتي). هي هيكل عمل جاهز للتجربة على خادم تملكه، وليست خدمة جاهزة.

## ما تحتاجه
- خادم لينكس (VPS) يدعم **KVM** أو يشغّل حاويات بصلاحيات (Redroid) وذاكرة 8 غيغابايت فأكثر. أرخص الخيارات: Hetzner/Contabo/RunPod (CPU) أو خادم GPU للأداء الأعلى.
- Docker.

## المكونات
| الملف | الوظيفة |
|---|---|
| `docker-compose.yml` | يشغّل أندرويد حقيقياً داخل حاوية (Redroid) ويفتح منفذ ADB |
| `controller.py` | واجهة HTTP صغيرة (FastAPI) تحوّل أوامر الذكاء الاصطناعي إلى أوامر ADB: لقطة شاشة، نقر، سحب، كتابة، تثبيت APK، تشغيل تطبيق |
| `tools.json` | تعريف «الأدوات» لتستدعيها نماذج الذكاء الاصطناعي (Function Calling) |

## التشغيل
```bash
docker compose up -d                       # أندرويد على المنفذ 5555
pip install fastapi uvicorn[standard] pillow
API_KEY=غيّر_هذا uvicorn controller:app --host 0.0.0.0 --port 8080
```
ثم اجعل الذكاء الاصطناعي يرسل الأوامر إلى `http://خادمك:8080` مع ترويسة `x-api-key`.

## كيف يتحكم النموذج به
حلقة وكيل (Agent loop): (1) النموذج يطلب `screenshot` (2) يرى الصورة (نموذج رؤية مثل Qwen2-VL أو Claude) (3) يقرر `tap(x,y)` أو `type("نص")` (4) يكرر. هذا ما تفعله أنظمة «Computer Use».

## تنبيهات
- ضع الخادم خلف مفتاح وجدار حماية؛ من يصل إليه يتحكم بالهاتف الافتراضي.
- لا تُدخل حسابات حقيقية (جوجل أو بنك) داخل المحاكي.
- دمجه داخل تطبيق بوصلة (أداة يستدعيها المحادثة) غير منجز بعد.
