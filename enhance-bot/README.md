# بوت المونتاج (Voi) — دليل الرفع على الاستضافة

## الملفات
| الملف | الوظيفة |
|---|---|
| `main.py` | **الملف الرئيسي** — شغّله: `python main.py` |
| `requirements.txt` | **ملف المكاتب** — تثبيت: `pip install -r requirements.txt` |
| `.env` | التوكن والإعدادات (فيه توكنك — لا تنشره) |
| `effects.py` | كل التأثيرات (129+) |
| `designer.py` | 150 قالب مصمم · `templates.py` 37 قالباً إضافياً |
| `cvlib.py` / `cvpipe.py` | الواقعية ودقة الآيفون (OpenCV) |
| `autograde.py` | التلوين التلقائي الذكي · `beats.py` كشف الإيقاع |
| `compose.py` | تجميع أوامر FFmpeg · `process.py` قراءة الفيديو |
| `art.py` | النصوص العربية والصور · `webapp.py` + `webapp/` محرر النصوص (تطبيق مصغّر) |
| `fonts/` (77 خطاً) · `models/` (شبكة التكبير ESPCN) | موارد |
| `Procfile`, `runtime.txt`, `Aptfile`, `Dockerfile`, `render.yaml`, `start.sh` | للاستضافات المختلفة |

## الرفع
1. ارفع المجلد كاملاً (مع `fonts/` و`models/` و`webapp/`).
2. أمر التثبيت: `pip install -r requirements.txt`
3. أمر التشغيل: `python main.py`
4. يحتاج **FFmpeg**: إن لم يكن مثبتاً على الاستضافة يُنزَّل تلقائياً عند أول تشغيل (static-ffmpeg).
5. Python 3.10 أو أحدث.

## محرر النصوص (التطبيق المصغّر)
ضع في `.env`: `WEBAPP_URL=https://رابط-استضافتك` (يجب أن يكون HTTPS ويصل لمنفذ `PORT`، الافتراضي 8080).

## ملاحظات
- شغّل نسخة واحدة فقط بنفس التوكن (وإلا يظهر خطأ Conflict).
- حدود تيليجرام: استقبال حتى 20MB، إرسال حتى 50MB.
- لأفضل دقة: يرسل المستخدم الفيديو كـ «ملف» 📎 وليس كفيديو.

## لوحة تحكم المسؤول
أرسل `/admin` من حساب مسؤول (ADMIN_IDS): إحصائيات تفصيلية، مستخدمون وبحث وتفاصيل كل مستخدم، إذاعة (بمعاينة وتأكيد)، حظر/رفع حظر، رسالة لمستخدم، جلسات نشطة، إشعارات فورية (مستخدم جديد/فشل عملية)، إعدادات (صيانة، إيقاف الفيديو/الصور، حد يومي، أقصى مدة)، حالة النظام، تنظيف الملفات، تصدير CSV.

## الحسابات وتسجيل الدخول
عند `/start` يظهر للمستخدم «تسجيل دخول / إنشاء حساب». إنشاء الحساب: اسم مستخدم ثم كلمة سر (يدوية أو توليد)، وتُخزَّن مشفّرة (scrypt). الدخول مرة واحدة ويبقى محفوظاً على تيليجرام المستخدم، و`/account` لحسابي (تغيير كلمة السر/خروج). سجل أعمال كل حساب خاص به. النظام مجاني حالياً وفيه تحضير للاشتراك (الخطة + تاريخ الانتهاء). المسؤول يدير الحسابات من `/admin` ← الحسابات، ويقدر يوقف إلزام الدخول من الإعدادات.

## المونتاج من الرابط
زر «مونتاج من خلال الرابط» (أو أرسل رابطاً مباشرة): تيك توك وإنستغرام فقط. يُجلب الفيديو بدون علامة مائية (tikwm ثم yt-dlp)، ثم: تعديل بالاستوديو، أو تعديل المصممين المحترفين، أو تحميل بدون تعديل (يُضغط بدون قص إن زاد عن 50MB). لإنستغرام الخاص/المقيّد ضع ملف كوكيز في `IG_COOKIES`.

## فصل الخلفية (جودة عالية)
عند أول تشغيل ينزّل البوت تلقائياً (في الخلفية، مرة واحدة) نموذجين إلى مجلد `models/`: `u2net_human_seg.onnx` (~170MB للأشخاص حتى بالملابس الداكنة) و`silueta.onnx` (~44MB للأجسام). يلزم إنترنت على الاستضافة؛ وإن تعذّر يعمل النموذج الصغير المرفق `u2netp.onnx` بجودة أقل. لتعطيل التنزيل: `PHOTO_MODELS=0`.

## التشغيل 24/7 والمراقبة
أمر التشغيل على الاستضافة: `python run_forever.py` (المشرف). يعيد تشغيل البوت خلال ثانية إن انتهى لأي سبب (مع تباطؤ تدريجي إن انهار مراراً). داخل البوت: نبض كل ثانية + خيط حارس مستقل يعيد التشغيل ذاتياً إن تجمّدت الحلقة `WATCHDOG_STALL` ثانية (افتراضي 45) أو تجاوزت الذاكرة `MAX_RSS_MB`. عند العودة بعد توقف يصلك تنبيه بمدة التوقف. شاشة «🛰 المراقبة 24/7» في `/admin`، ونقطة `/health` (JSON، ترجع 503 عند التجمّد) لأي مراقب خارجي مثل UptimeRobot، وHEALTHCHECK مضبوط في Dockerfile.

## قوائم البيانات والنسخ الاحتياطي
`/admin` ← «قوائم البيانات»: أعداد المستخدمين والحسابات والجلسات والعمليات والإشعارات، حجم القاعدة ومسارها، وتصفح كل قائمة. نسخ احتياطي تلقائي كل 6 ساعات (آخر 10 في `backups/`) + نسخة يومية ترسَل لك على تيليجرام. «استرجاع نسخة»: أرسل ملف `.db` فيفحصه ويعرض محتواه ثم يستبدل البيانات (بعد حفظ نسخة أمان). **للحفظ الدائم على Docker/Render** اربط Volume وضع `DB_PATH=/data/stats.db` (وإلا قد تُمسح القاعدة عند إعادة النشر؛ لهذا تصلك النسخة اليومية).

## التوجيهات (نشاط المستخدمين → المسؤول)
`/admin` ← «التوجيهات»: دخول شخص جديد/حضوره (الاسم، اليوزر، الآيدي، الحساب)، إنشاء الحسابات (الاسم + كلمة السر **إن ولّدها البوت** فقط)، رسائلهم، ما يرفعونه (يُنسخ لك)، شنو استخدموا من أدوات، والنتائج المرسلة لهم. تُجمَّع الإشعارات المتكررة وتصل صامتة، ولكل نوع زر تشغيل/إيقاف. لا يُوجَّه ما يكتبونه عند إدخال الاسم وكلمة السر ولا كلمات السر التي اختاروها بأنفسهم (محفوظة مشفّرة). رسالة الترحيب تخبر المستخدم أن الإدارة قد تطّلع على نشاطه.
