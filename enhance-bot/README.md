# بوت تحسين الفيديو (HDR / ألوان / 2K)
أرسل فيديو ← اختر: «ألوان وتحسين» أو «HDR عالية دقة» أو «دقة 2K» ← عدّاد يتحرك أثناء المعالجة ← يصلك الفيديو المحسّن.
المعالجة بـ FFmpeg (إزالة تشويش، توضيح، ألوان، منحنيات HDR-look، تكبير Lanczos). **ليست ذكاءً اصطناعياً** ولا HDR10 حقيقياً (الخرج SDR بمظهر HDR).
حدود تيليجرام: تنزيل حتى 20MB، رفع حتى 50MB (يُضبط معدل البت تلقائياً).

تشغيل: `pip install -r requirements.txt` + ffmpeg ثم `.env` فيه BOT_TOKEN ثم `python bot.py`.
