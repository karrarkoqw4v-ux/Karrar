# استوديو المونتاج (بوت تيليجرام)
فيديو + أزرار تحته: كل تأثير تضغطه يُطبَّق مباشرة على نفس رسالة الفيديو (معاينة حية 4 ثوانٍ مع الصوت)، مع تراجع ومسح و25 قالباً جاهزاً بمعاينة صور، ثم «معالجة وتصدير» للفيديو الكامل.

## المكتبات
- **FFmpeg**: مونتاج وفلاتر وانتقالات وصوت (قص، سرعة، نسب، نص عربي، موسيقى، تثبيت vidstab…).
- **OpenCV + NumPy**: واقعية فائقة بمعالجة إطار بإطار — HDR بدمج التعريضات (Mertens)، Retinex للإضاءة المنخفضة، Dark-Channel لإزالة الضباب، NLM لتنقية التشويش، CLAHE، تضخيم التفاصيل، توازن أبيض، ألوان فيلمية ACES، تكبير + توضيح.
- **Pillow + raqm**: النصوص العربية والمعاينات والقوالب. **aiogram 3**: البوت.
لا يستخدم ذكاءً اصطناعياً؛ رفع الدقة يكبّر ويوضّح ولا يخترع تفاصيل.

## أوامر
`/start` `/menu` `/id` — للأدمن (`ADMIN_IDS` في .env): `/stats` `/bcast`.

## حدود تيليجرام
تنزيل حتى 20MB، رفع حتى 50MB (يُضبط معدل البت)، مدة قصوى 3 دقائق (`MAX_DURATION`).

## التشغيل
`pip install -r requirements.txt` + ffmpeg ثم `.env` (BOT_TOKEN, ADMIN_IDS) ثم `python bot.py` — أو `docker build` ثم `docker run --env-file .env`.
الاختبارات: `python tests/test_effects.py out_dir` و`python tests/test_flow.py clip.mp4 music.mp3`.
