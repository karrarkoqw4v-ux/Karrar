# بوت المونتاج (Voi) — دليل الرفع على الاستضافة

## الملفات
| الملف | الوظيفة |
|---|---|
| `main.py` | **الملف الرئيسي** — شغّله: `python main.py` |
| `requirements.txt` | **ملف المكاتب** — تثبيت: `pip install -r requirements.txt` |
| `.env` | التوكن والإعدادات (فيه توكنك — لا تنشره) |
| `effects.py` | كل التأثيرات (129+) |
| `designer.py` | 150 قالب مصمم · `templates.py` 37 قالباً إضافياً |
| `cvlib.py` / `cvpipe.py` | الواقعية ودقة الآيفون (OpenCV) |
| `autograde.py` | التلوين التلقائي الذكي · `beats.py` كشف الإيقاع |
| `compose.py` | تجميع أوامر FFmpeg · `process.py` قراءة الفيديو |
| `art.py` | النصوص العربية والصور · `webapp.py` + `webapp/` محرر النصوص (تطبيق مصغّر) |
| `fonts/` (77 خطاً) · `models/` (شبكة التكبير ESPCN) | موارد |
| `Procfile`, `runtime.txt`, `Aptfile`, `Dockerfile`, `render.yaml`, `start.sh` | للاستضافات المختلفة |

## الرفع
1. ارفع المجلد كاملاً (مع `fonts/` و`models/` و`webapp/`).
2. أمر التثبيت: `pip install -r requirements.txt`
3. أمر التشغيل: `python main.py`
4. يحتاج **FFmpeg**: إن لم يكن مثبتاً على الاستضافة يُنزَّل تلقائياً عند أول تشغيل (static-ffmpeg).
5. Python 3.10 أو أحدث.

## محرر النصوص (التطبيق المصغّر)
ضع في `.env`: `WEBAPP_URL=https://رابط-استضافتك` (يجب أن يكون HTTPS ويصل لمنفذ `PORT`، الافتراضي 8080).

## ملاحظات
- شغّل نسخة واحدة فقط بنفس التوكن (وإلا يظهر خطأ Conflict).
- حدود تيليجرام: استقبال حتى 20MB، إرسال حتى 50MB.
- لأفضل دقة: يرسل المستخدم الفيديو كـ «ملف» 📎 وليس كفيديو.

## لوحة تحكم المسؤول
أرسل `/admin` من حساب مسؤول (ADMIN_IDS): إحصائيات تفصيلية، مستخدمون وبحث وتفاصيل كل مستخدم، إذاعة (بمعاينة وتأكيد)، حظر/رفع حظر، رسالة لمستخدم، جلسات نشطة، إشعارات فورية (مستخدم جديد/فشل عملية)، إعدادات (صيانة، إيقاف الفيديو/الصور، حد يومي، أقصى مدة)، حالة النظام، تنظيف الملفات، تصدير CSV.
